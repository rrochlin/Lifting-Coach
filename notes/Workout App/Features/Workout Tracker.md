# Description
The heart of the app - any fitness app worth its salt starts here and get's this right. The workout tracker is used during workouts for the user to log in real time completed sets, weights, reps, and notes about the workout.

## Requirements
- User can see the current workout planned
- User can check off Set's when completed
- An Exercise is highlighted as "active" when it is being currently done
- User can reorder Exercises with tap/drag motion
- User can delete and add sets as needed
- User can add Exercises to a workout as needed
- user can delete Exercises from a set as needed
- After a workout is completed a rest timer starts
- Tracker view is compact and focuses on whats important to the user at the current moment. i.e. what's next and what the current target is
- User can log notes and RPE for sets and exercises
